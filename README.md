# 🧠 Enterprise HR AI — Workforce Intelligence & Upskilling Platform

A production-quality HR intelligence system that answers three questions:
1. **Who is at risk of quitting?** — XGBoost attrition ML model
2. **Where are the skill gaps?** — O\*NET essential skills gap engine
3. **What should each employee learn next?** — Rule-based + semantic upskilling recommendations

Built with **FastAPI** backend, **Streamlit** dashboard, and **16 executed Jupyter notebooks** documenting every step.

## ⚠️ Data Warnings — Verified

### Warning 1: Employee ID Overlap
- `employee_performance_pro.csv` (500 employees) and `Employee_Performance_Dataset.csv` (5,000 employees) have **zero overlapping IDs** — confirmed by code in NB02 and NB04.
- **Rule applied**: No per-employee join. Only department-level engagement aggregations used.

### Warning 2: JobRole vs O*NET Title Mismatch
- Employee files use casual titles (`"Auditor"`, `"Developer"`). O\*NET uses formal titles (`"Accountants and Auditors"`, `"Software Developers"`).
- **Exact string matches: 0** — verified in NB04 and NB11.
- **Solution**: Explicit manual lookup dictionary built in NB11 with rationale for each of 13+ roles. See [`docs/role_mapping.md`](docs/role_mapping.md).

## 🚀 Setup & Running

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run notebooks (in order, already executed)
```bash
cd notebooks/
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=600 01_data_understanding.ipynb
# ... repeat for 02 through 16
```

### 3. Start the FastAPI backend
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
API docs available at: `http://localhost:8000/docs`

### 4. Start the Streamlit dashboard
```bash
streamlit run frontend/app.py
```
Dashboard available at: `http://localhost:8501`

## 🎯 Skill Gap Severity Thresholds

Scaled to a **500-person population**:

| Level | Condition | Rationale |
|-------|-----------|-----------|
| 🔴 **HIGH** | ≥30% of employees lacking + O\*NET importance ≥3.5/5 | 1 in 3 employees can't perform a critical skill = systemic gap |
| 🟡 **MEDIUM** | ≥15% lacking + importance ≥3.0/5 | 1 in 6 = material planning-level gap |
| 🟢 **LOW** | Everything else | Monitor, no immediate action |

## 🔬 Monitoring

### Data Drift
```bash
python monitoring/drift_monitor.py --prod data/processed/employee_intelligence.csv
```
Uses **Kolmogorov–Smirnov test** (p < 0.05 = drift detected) on: Age, MonthlySalary, YearsAtCompany, WorkLifeBalanceScore, OvertimeHoursPerMonth.

### Model Performance
```bash
python monitoring/model_monitor.py \
  --predictions data/predictions/predictions_YYYYMMDD.jsonl \
  --actuals data/processed/employee_attrition_processed.csv
```

### Retraining Triggers
- Data drift p-value < 0.05 on any monitored feature
- F1 drops below **0.60**
- 6 months of new data collected
